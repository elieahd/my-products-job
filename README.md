# My Products Jobs: Spring Batch Workshop

A hands-on workshop to learn **Spring Batch** by building `my-products-jobs`, a small application that imports products
from a CSV file, exports them back to CSV, and finally runs as a command-line batch job.

## Workshop plan

| # | Part                                                   | Theory / Specification                        | Step-by-step guide                                |
|---|--------------------------------------------------------|-----------------------------------------------|---------------------------------------------------|
| 1 | **Spring Batch 101**                                   | [01-spring-batch.md](docs/01-spring-batch.md) | n/a                                               |
| 2 | **My Products** (domain and starting point)            | [02-my-products.md](docs/02-my-products.md)   | n/a                                               |
| 3 | **Feature 1**: Import products from CSV                | [03-feature1.md](docs/03-feature1.md)         | [03-feature1-steps.md](docs/03-feature1-steps.md) |
| 4 | **Feature 2**: Export products to CSV                  | [04-feature2.md](docs/04-feature2.md)         | [04-feature2-steps.md](docs/04-feature2-steps.md) |
| 5 | **Feature 3**: Convert the REST API to a CLI batch job | [05-feature3.md](docs/05-feature3.md)         | [05-feature3-steps.md](docs/05-feature3-steps.md) |

For each feature, read the **specification** first (objective, input/output, business rules), then follow the **steps**
to implement it.
